Контролните суми са в `SHA256SUMS.txt` (Windows) и `SHA256SUMS-linux.txt` (Linux). Ако в изданието има `SHA256SUMS-linux.txt.asc`, Linux файловете са подписани с GPG; иначе пакетите са неподписани ([SIGNING.md](https://github.com/biramentv-ux/p2p-pure/blob/main/docs/SIGNING.md)).
Checksums are in `SHA256SUMS.txt` (Windows) and `SHA256SUMS-linux.txt` (Linux). If the release has `SHA256SUMS-linux.txt.asc`, the Linux files are GPG-signed; otherwise the packages are unsigned.
