# Стратегия за тестване

Дата: 21 октомври 2026. Отнася се за уеб PWA, Android и iOS (Capacitor), които делят един и същ UI код.

## Пирамида и текущо състояние

| Слой | Какво покрива | Текущо състояние | Инструмент |
|---|---|---|---|
| Unit | криптография, идентичност, история, сигнализация, разговори, снимки, контроли | **226 теста, 24 файла, всички минават** | Vitest, fake-indexeddb |
| Mock Worker | API на сигналния Worker, Telegram webhook, TTL, кратки кодове | **51 проверки** | `npm run test:mock` |
| UI с два браузъра | кратък код между две страници | **9 проверки** | `npm run test:mock-ui` |
| E2E чат | локация, отказ за локация, изтриване на чат от двете страни | **11 проверки** | `npm run test:chat` |
| E2E разговор | аудио и видео между два браузъра | **13 проверки** | `npm run test:call` |
| Мобилна среда | overlay файлове, rpId за native | **10 проверки + unit** | `npm run test:mobile`, `test:mobile-emu` |
| Native | Android и iOS на устройство | **Не е тествано** | — |

## Пропуски, по приоритет

1. **Native устройства (P0).** Разрешенията за камера, микрофон и локация във WebView не са проверени на физическо устройство. Без това не може да има публикуване. Нужен е Android телефон и iPhone с Xcode.
2. **Визуална регресия (P1).** Екраните се проверяват ръчно. Добавяне на Playwright снимки с праг за разлика (за екраните: идентичност, контакти, чат, разговор).
3. **Достъпност (P1).** Липсва автоматична проверка. Добавяне на axe-core в e2e за всеки екран.
4. **`tests/e2e/ui.mjs` е нестабилен (P1).** Пада при свързване на WebRTC. Причината е в headless средата. Да се замени с `connectPair` (3 опита), който вече се ползва в call.mjs.
5. **Скелетони и glider на табовете (P2).** Няма тест, който проверява, че табът е активен визуално или че скелетонът се сменя със списък. Добавяне на unit тест с Testing Library.
6. **Кратък код при провал на Worker-а (P2).** Съществуващият тест покрива happy path и TTL. Липсват тестове за 5xx отговор и за изтекла покана при втори опит.

## Какво да не се тества

- Тривиални getters и setters.
- Самата библиотека за QR код и jsQR.
- Генерираните файлове (`dist`, `android/app/build`).

## Команди за пълен преглед

```bash
npm test                    # unit
npm run lint                # oxlint
npm run build               # tsc + билд
npm run test:mock
npm run test:mock-ui
npm run test:chat
npm run test:call
npm run mobile:check
```

Е2Е тестовете изискват системен Chromium в `/opt/pw-browsers` (или `CHROME_PATH`) и фалшиви медийни устройства, които се включват автоматично.
